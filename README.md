# Single price grid component

![Design preview for the Single price grid component challenge](./design/desktop-preview.jpg)

Solution to the Frontend Mentor **Single price grid component** challenge - a responsive component built from the provided design.

**Live demo:** https://erfan-revenant.github.io/Single-price-grid-component/

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and media queries
- Bundled webfonts and SVG assets from the challenge starter files

## Run locally

```bash
git clone https://github.com/ErfanBagheri404/Single-price-grid-component.git
cd Single-price-grid-component
```

Open `index.html` in a browser. Nothing to install or compile.
